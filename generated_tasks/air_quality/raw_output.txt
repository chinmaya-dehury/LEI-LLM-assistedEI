**New Tasks for Edge Device Execution:**

1. **PM2.5 vs PM10 Source Differentiation**  
   *Description:* Analyze the ratio of PM2.5 to PM10 concentrations to infer pollution sources (e.g., traffic vs. dust). Higher PM2.5/PM10 ratios may indicate vehicular emissions, while elevated PM10 with lower PM2.5 could suggest dust or construction activity.  
   *Efficiency:* Lightweight calculation using basic ratio comparisons.  

2. **Daily Pollutant Contribution Trend**  
   *Description:* Track the dominant pollutant (e.g., PM2.5, NO2, O3) on a per-day basis to identify patterns (e.g., traffic-driven peaks vs. industrial spikes).  
   *Efficiency:* Aggregates hourly data into daily summaries for quick analysis.  

3. **NH3 Correlation with Agricultural Activity (Heuristic)**  
   *Description:* Flag elevated NH3 levels (above 90th percentile) as potential indicators of agricultural activity, even without explicit agrarian data.  
   *Efficiency:* Simple threshold-based alert for NH3 anomalies.  

---

**Rationale:**  
- **Resource Alignment:** Current CPU/memory usage is minimal (0.01% CPU, 3.1% MEM), allowing for additional lightweight analyses.  
- **Unique Insights:**  
  - **PM2.5/PM10 Ratio:** Clarifies source types (e.g., traffic vs. dust) for localized mitigation.  
  - **Daily Contribution Trends:** Helps prioritize pollutant-focused interventions (e.g., traffic control on days with NO2 dominance).  
  - **NH3 Alerts:** Provides heuristic guidance for agricultural pollution monitoring.  
- **Avoids Duplicates:** These tasks complement existing ones (e.g., source inference, seasonal trends) by focusing on granular, actionable patterns.  

**Implementation Notes:**  
- Use SQLite aggregation for daily trends and ratio calculations.  
- Prioritize numpy/pandas for efficiency, but limit operations to avoid memory spikes.  
- Ensure NH3 alerts are triggered only during specific hours (e.g., early mornings) for agricultural relevance.  

These tasks are optimized for edge execution while expanding actionable insights for citizens.
